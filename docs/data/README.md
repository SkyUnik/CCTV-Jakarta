# CCTV data review

`cameras.scraped.json` is public provider metadata collected from the Bina Marga
Tol Dalam Kota page. It is not ready for automatic playback.

Before copying a record into the reviewed `cameras.json` dataset:

1. Verify which carriageway it observes.
2. Set `side` to `A` for travel away from KM 0 at Cawang or `B` for travel
   toward KM 0.
3. Add `coordinates` in `[longitude, latitude]` order.
4. Project the coordinate onto the reviewed highway geometry and store the
   result in `roadPositionM`.
5. Set `curationStatus` to `verified` and `enabled` to `true` only after all
   values have been checked.

Provider-controlled fields are `providerCameraId`, `name`, `streamUrl`,
`sourcePage`, `km`, and `scrapedAt`. Editorial fields are `side`, `coordinates`,
`roadPositionM`, `enabled`, `curationStatus`, and `notes`.

Repeated labels are expected. Records are identified by the provider's numeric
camera/video ID, not by label or stream URL.

For a public camera that is not collected from Bina Marga, use
`npm run camera:add -- --help`. This avoids JSON syntax mistakes and prevents
duplicate stream URLs. The new entry is intentionally disabled until reviewed.

`stream-compatibility.json` is a point-in-time playlist-only report generated by
`npm run streams:check`. It is diagnostic data, not an allowlist: a passing
playlist can later go offline, and a failed camera must not be enabled without
editorial coordinate/direction review. The checker never requests video
segments.
